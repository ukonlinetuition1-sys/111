# AI Routing

Use specialists only when they materially improve the result.

## Budget
- Simple task: 0.
- Specialist task: 1.
- Important implementation: 1 implementer + 1 independent verifier.
- High-risk/cross-domain: up to 3 relevant specialists.
- Full roster: explicit full-roster audit/release challenge only.

Stop when another role would duplicate work, the result is evidenced/verified, or the blocker is access/approval.

## Route
- Website implementation → Frontend Developer.
- Layout/visual system → UI Designer.
- Accessibility/cross-device → Accessibility/QA.
- SEO/metadata/internal linking → SEO.
- Forms/scripts/integrations/data → Security/Privacy when material.
- Wix configuration → Wix-native tooling first; bounded editor/browser work only when required.
- Tutoring automation → workflow specialist; pedagogy/exam accuracy → education/content; student-facing output → independent QA.
- Multi-source research → research specialist; add domain expertise only when interpretation requires it.

## Context
Pass only objective, relevant evidence, constraints, deliverable and verification. Return only useful evidence, action, risk and confidence. Never load PROJECT_STATE, WORK_QUEUE or roster material merely because it exists.

Treat Agency as an expert library, not a meeting.
