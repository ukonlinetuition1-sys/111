# Agency Roster Policy

The installed Agency roster is an optional specialist library. Use `AI_ROUTING.md`; ordinary tasks normally need 0–2 specialists.

Run a full-roster sweep only when the user explicitly requests one or for a deliberate broad release challenge. Irrelevant roles should return NOT_APPLICABLE briefly; never invent blockchain, XR, GIS, game-engine, healthcare or other unrelated work to satisfy roster count.

Most relevant here: Design, relevant Engineering, Marketing/SEO, Product, Project Management, Research, Sales/conversion, Security/privacy, Analytics/Support and Testing.

Earlier full-roster-by-default project control is superseded by selective routing.
