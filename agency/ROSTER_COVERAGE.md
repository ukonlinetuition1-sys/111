# Agency Roster Policy

The Agency roster is an optional specialist library, not a mandatory execution checklist.

## Default
Use `AI_ROUTING.md`. Most tasks need 0–2 specialists. Select by domain and evidence need.

## Full-roster use
A complete roster sweep is justified only when:
- the user explicitly requests a full-roster audit; or
- a release-gate exercise deliberately seeks broad independent challenge.

Even in a full sweep, irrelevant domains return a terse NOT_APPLICABLE result. Do not create artificial blockchain, XR, GIS, game-engine, healthcare or other unrelated work.

## Useful divisions for this project
Design, relevant Engineering, Marketing/SEO, Product, Project Management, Research, Sales/conversion, Security/privacy, Support/analytics and Testing.

## Usually irrelevant unless requirements change
Game Development, GIS, Healthcare-specific roles, Spatial Computing and highly specialised infrastructure/regulated roles.

## Historical note
Earlier project control required every source agent to complete an applicability gate. That approach has been superseded because it adds context/execution cost without improving ordinary task quality. The installed roster may remain available for targeted use.
