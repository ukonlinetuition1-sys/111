# Dungeon of the Shattered Crown

A lightweight first-person, D&D-inspired browser dungeon crawler.

## Current playable slice

- First-person dungeon presentation
- Seven connected rooms
- Directional exploration
- d20 attack rolls, armour class and critical hits
- Four enemies including a boss
- HP, potions, XP, gold and levelling
- Loot that permanently improves attack or AC for the run
- Adventure log
- Responsive desktop/mobile interface
- Defeat and victory states

## How to run

Open `index.html` in a browser. No build tools or dependencies are required.

## Design direction

The intended game is not a typing adventure. It should become an atmospheric browser dungeon crawler with meaningful D&D-style choices, procedural variation and short replayable runs.

## Project rules

1. Keep development isolated from the tuition website until a release is deliberately approved.
2. Every release must remain playable without external frameworks.
3. Mechanics come before visual complexity.
4. Add depth through encounters, choices and replayability rather than grind.
5. Mobile play must remain viable.
